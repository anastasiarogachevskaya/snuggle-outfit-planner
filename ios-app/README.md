# Layerly iOS (Capacitor wrapper)

This folder is the scaffold for the **separate** iOS repository. It lives inside the web repo only so Lovable can generate/edit it — you extract it into its own GitHub repo when you're ready.

## Structure

```
ios-app/
├── capacitor.config.ts        # Production: loads https://www.layerly.online
├── capacitor.config.local.ts  # Local dev: bundles web/dist
├── package.json               # Capacitor 7 + native plugins
├── web/                       # Becomes a git submodule → layerly-web repo
├── ios/                       # Generated by `npx cap add ios` (not committed here)
└── .github/workflows/build-ios.yml
```

## Extract into its own repo

1. Copy this `ios-app/` folder out of the Lovable download (or `git clone` the web repo and copy it).
2. Create an empty GitHub repo, e.g. `layerly-ios`.
3. Push the contents (not the folder itself) to it:
   ```bash
   cp -R ios-app/ ~/layerly-ios && cd ~/layerly-ios
   git init && git add . && git commit -m "Initial iOS wrapper"
   git remote add origin git@github.com:you/layerly-ios.git
   git push -u origin main
   ```
4. Add the web repo as a submodule at `web/`:
   ```bash
   git submodule add git@github.com:you/layerly-web.git web
   git commit -m "Add web submodule"
   ```

## First build

```bash
bun install
cd web && bun install && bun run build && cd ..
npx cap add ios         # generates ios/App/App.xcworkspace
npx cap sync ios
npx cap open ios        # opens Xcode
```

In Xcode: select the **App** target → Signing & Capabilities → set your Apple Developer Team and Bundle Identifier `online.layerly.app`. Add the **Sign in with Apple** capability.

## Two config modes

- **Default (`capacitor.config.ts`)** — loads the live site from `https://www.layerly.online`. Updates ship instantly with your web deploys; no App Store release needed for content changes.
- **Local (`capacitor.config.local.ts`)** — bundles `web/dist` into the app. Use for offline testing or App Review builds when you don't want the app to depend on the live URL.

Switch by copying whichever config over `capacitor.config.ts` before `npx cap sync ios`.

## Deep links

The app registers the `layerly://` custom scheme. `@capacitor/app`'s `appUrlOpen` listener forwards incoming URLs to the web view so `/auth-callback` can consume tokens from magic links and OAuth redirects.

Universal Links for `https://www.layerly.online/auth-callback` also work once you host `apple-app-site-association` on the web domain (out of scope for this scaffold).

## CI

`.github/workflows/build-ios.yml` is a stub for GitHub Actions: checkout with submodules, build web, `npx cap sync ios`, archive, upload to TestFlight. Fill in the App Store Connect API key secret before enabling.

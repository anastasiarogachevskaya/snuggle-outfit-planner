# Calmer Layerly landing page

## Direction
Build the selected **Serene minimalist v4** direction as a calmer, more spacious landing page. Keep Layerly’s Nordic sage palette and friendly modern type, while adapting the selected composition to the product’s real links and claims.

## What will change
- Simplify the top bar to the Layerly name, a small set of useful links, and quiet sign-in access.
- Recompose the opening around one clear promise, one primary **Try Layerly — no account needed** action, and a subtle account sign-in path.
- Replace the current recommendation card with a polished phone-style preview of Layerly’s real layered outfit experience.
- Use the selected wide two-part composition on larger screens, then collapse it into one focused vertical flow on phones.
- Reduce repeated reassurance text and remove competing actions from the first screen.
- Reorganize the footer into a cleaner, lower-emphasis set of existing destinations without inventing Release Notes, Terms, or Beta links.
- Preserve native-app redirect, session, launch diagnostics, and analytics behavior exactly as they work now.

## Visual system
- Palette: Nordic Sage — `#F7F7F2`, `#A8B894`, `#314238`, `#D7A98C`, implemented as semantic theme tokens.
- Typography: Outfit headings and Figtree body copy.
- Style: soft off-white canvas, dark green text, restrained borders and shadows, minimal motion, and generous spacing.
- Accessibility: readable contrast, visible keyboard focus, reduced-motion support, and comfortable mobile tap targets.

## Validation
- Check the landing page at phone and desktop sizes for crowding, overflow, and first-screen hierarchy.
- Confirm the try, sign-in, navigation, and footer links still reach their existing pages.
- Confirm signed-in and local-profile visitors still bypass the landing page correctly.
- Run the existing automated checks and verify the final page visually in the preview.
